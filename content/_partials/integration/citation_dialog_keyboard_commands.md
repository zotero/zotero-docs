In the Citation Dialog the following keyboard shortcuts are available:

-   Press right and left arrows to move the cursor between bubbles in citations with multiple items
-   Press Delete/Backspace with the cursor before a bubble to remove its item from the citation
-   In a citation with multiple items, press Home to move the cursor before the first bubble. Similarly, press End to move the cursor after the last bubble.
-   In a citation with multiple items, press Shift-ArrowLeft when a bubble is selected to swap the selected
bubble with the bubble before it. Similarly, Shift-ArrowRight will swap the selected bubble with the bubble after it.
-   Press Space or Down Arrow when a bubble is selected to open its citation details popup where the citation can be customized
-   Enter/Return adds a selected item to the citation as a new bubble. When no item is selected, Enter/Return will accept the dialog
-   Cmd+Return/Ctrl+Enter will always accept the dialog regardless of where the focus/selection is
-   Type "p.45-48" or ":45-48" after a bubble of a cited item and press Enter/Return to add a specific page or page range locator. You can type any other locator in its full or short form (e.g. chapter 13 or chap 13).
Refer to the dropdown in the citation details popup of a bubble for the full list of locators.
- To quickly add a page locator right after adding a new item, you may just type the number of the page range
that needs to be cited (e.g. 10-15) - it will be automatically converted to the page locator of the last added bubble. To undo the automatic conversion, press Cmd/Ctrl+Z.
-   Type "ibid" to automatically select the last cited work. This works with all citation styles, regardless of whether "ibid" is actually used in citations. If you use Zotero in a language other than English, use the corresponding abbreviation instead of ibid., e.g. "ebd." in German.
-   Select a citation with the mouse or left/right arrow keys and press Down Arrow or Space to open the citation details popup. Use Tab and Shift-Tab to move between the different elements, use the Up and Down Arrow keys to change the locator type in the locator dropdown list, and the Space to toggle the "Omit Author" checkbox.
- In List mode, use Up/Down Arrows to navigate the list of options. Press Enter/Return to add the highlighted item to the citation.
- In Library mode, use right/left arrows to navigate the Selected/Open/Cited item cards. In the main items table, use Enter to add the selected item to the citation. You may select a range via Shift+Up/Down Arrows - Enter will add all selected items in one step. If you want to select multiple non-adjacent items, use Cmd/Ctrl+Up/Down Arrows to navigate the table without changing which items are selected, and use Space to select/de-select items.
