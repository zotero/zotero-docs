# I've lost my password. How can I recover my Zotero account?
If you've forgotten your password, you can [request a reset](https://www.zotero.org/user/lostpassword). This is also linked from the login page.

If you receive an email saying there is no Zotero account associated with your address, note that an account isn't required to use Zotero. If you previously used Zotero it's possible you were just using it locally without syncing. If you have other email addresses, you can try resetting your password with those, but otherwise your data would be on the computer where you last used Zotero, and you can create an account and set up syncing to transfer your data. If you do have Zotero running locally, you can check the Sync or Account pane in your [preferences](/support/preferences) to see if you previously set up syncing with a different account.
